## 6. Traduction de l'algorithme de la question 5 en Python

```python
min_temp = float('inf')
max_temp = float('-inf')

for i in range(31):
    temperature = float(input("Entrer une température : "))
    if temperature < min_temp:
        min_temp = temperature
    if temperature > max_temp:
        max_temp = temperature

etendue = max_temp - min_temp
print("L'étendue est :", etendue)
```[cite: 1]
